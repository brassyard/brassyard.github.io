Privacy Policy

Last updated: November 24, 2026

Brassyard Publisher is a private tool used only by the owner of the Brassyard YouTube channel. It is not offered to, and does not accept sign-ins from, other people.

What the tool accesses

With the channel owner's authorization, the tool uses YouTube API Services to upload the channel's own videos, captions and thumbnails and to read basic information about the owner's own channel. It also uses Google Drive to store the channel's own production files in files it creates.

What we collect and share

The tool does not collect, sell or share personal data of any third party. OAuth tokens are stored as encrypted secrets in the channel's private build system and are used only to perform the actions above on the owner's own accounts.

YouTube API Services

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.
